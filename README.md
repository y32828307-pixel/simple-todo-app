# simple-todo-app
A simple to-do app

## How to open

No build step or install is needed. Either:

- Double-click `index.html` to open it in your browser, or
- Serve the folder locally, e.g. `python3 -m http.server 8000`, then visit http://localhost:8000.

## How to use

- **Add a task:** type in the input box and press **Enter** or click **Add**.
- **Complete / un-complete:** click the checkbox next to a task. Completed tasks are struck through.
- **Delete:** click **Delete** on the task's row.

Tasks are saved in your browser's local storage, so they persist after a page refresh (per browser and per origin).
